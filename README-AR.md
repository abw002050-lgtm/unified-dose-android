# Unified Dose Android — مشروع تجريبي

هذا مشروع Android مستقل يعرض موقع المعاينة عبر الإنترنت داخل WebView.
الرابط: https://abw002050-lgtm.github.io/unified-dose-pwa-preview/

## البناء
ملف `.github/workflows/build-apk.yml` يبني APK تجريبيًا عند الدفع إلى `main` أو تشغيل Workflow يدويًا.
بعد نجاح التشغيل: افتح Actions > آخر تشغيل ناجح > Artifacts > `unified-dose-debug-apk` ونزّل الملف.

## تنبيهات
- هذه نسخة Debug تجريبية وليست إصدارًا موقّعًا للتوزيع النهائي.
- لا ترفع مفاتيح توقيع أو كلمات مرور أو بيانات مرضى.
- التطبيق يحتاج إلى الإنترنت، ولا يضمن العمل دون اتصال.
- يجب أن يراجع الطبيب المحتوى الطبي قبل أي استخدام سريري.
